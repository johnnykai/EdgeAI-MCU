核心學習感想
1. 從「盲目軟體堆疊」到「軟硬體底層整合」
在過去的開發經驗中，多數是直接調用現成的函式庫。然而在這次實作中，為了驅動 VL53L0X 與 MPU6050，我必須深入配置 I2C1 匯流排並手動修改底層驅動檔案（如 VL53L0X.cpp）。這讓我深刻體會到，一個優秀的工程師不能只做上層開發，必須具備理解底層硬體暫存器與驅動協議的架構思維，才能真正優化系統的運作效率。 
2. 生成式 AI 是強大的開發協同者，而非替代者
在雙按鈕網頁控制與環境監測的項目中，我嘗試將生成式 AI（Gemini / ChatGPT）納入開發流程。我發現 AI 能夠極高效率地幫我搭建出 HTML 前端框架與邏輯骨架，但關鍵的硬體引腳對接、WiFi 訊號除錯與多模態提示詞優化，依然高度依賴開發者自身的工程核心素養。這重塑了我對「AI 時代下工程師角色」的認知——AI 是放大生產力的槓桿，而技術底蘊才是控制槓桿的關鍵。 
3. 以「使用者為本」的技術實踐
在「盲人輔助物體辨識系統」的優化過程中，我得到了極大的啟發。技術再強大，若缺乏良好的 UI/UX 設計也是枉然。為了適應盲人操作，我學會克制「想把所有功能塞進網頁」的工程師思維，改以大區塊、高對比的直覺介面，搭配精準限制在 30 字內的口語化 TTS 語音反饋。這讓我明白，技術的價值不在於複雜度，而在於能否真正解決使用者的痛點。
