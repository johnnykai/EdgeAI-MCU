# 🚀 邊緣控制與 AIoT 智慧應用實作特輯

本專案基於 **AMB82-mini** 開發平台，深度整合傳統微處理器控制、底層傳感器驅動（I2C/SPI）與前沿的 **Edge AI** 視覺模型、**Gemini 多模態大語言模型**，實現一系列從硬體端到雲端協同的智慧物聯網應用。

---

## 📂 實作項目展示

### ⚙️ 項目一：網頁伺服器雙按鈕控制 LED

#### 🛠️ 開發流程與架構
* **AI 協同開發**：將 `WebServer_ControlLED.ino` 原始碼提供給 Gemini 或 ChatGPT，優化並修改程式架構，使其支援雙獨立虛擬按鈕，分別控制藍色 LED（`LED_B`）與綠色 LED（`LED_G`）。
* **介面與部署**：利用 Google AI Studio 或 ChatGPT 生成 HTML 前端介面，並將網頁程式架設（Hosting）於 **AMB82-mini** 開發板。
* **遠端操控**：手機連線至 AMB82-mini 伺服器，即可透過網頁端跨平台操作實體硬體。

#### 📊 成果展示
* 手機螢幕顯示已成功連線至運行 `WebServer_ControlLEDx2` 之伺服器網頁，可獨立開關 LED B 與 LED G。

### 🎙️ 項目二：Edge AI 語音助理與氣象查詢

#### 💡 功能說明
* **系統配置**：於邊緣端配置 **Gemini API Key** 並選擇繁體中文語系。
* **智慧問答機制**：系統即時串接氣象資訊API，以結構化語音與文字回覆當前氣溫、濕度及今日天氣預報。例如查詢「基隆天氣」時，系統能自動提供詳盡的在地化氣象數據。

### 🧠 項目三：YOLOv7 視訊串流物件偵測演示

#### 🔬 核心技術
* **輕量化即時偵測**：利用 **YOLOv7** 深度學習模型進行邊緣端即時物件偵測，可精準辨識人（person）、車輛（car/bicycle/motorcycle/bus/truck）等多元生活目標。
* **低延遲串流實測**：結合 **WebSocket Viewer** 技術，在實驗室場域成功捕捉影像並實時框列出多名人員與周邊設備。

### ♿ 項目四：視覺輔助智慧物體辨識系統（盲人無障礙優化）

#### 🌐 專案部署流程
1. **GitHub Pages 部署**：將 `app-visual_assistant` 範例專案分叉（Fork）至個人帳號。
2. **靜態網頁生成**：於專案的 `Settings` > `Pages` > `Branch` 選擇 `Main` 分支並點擊 Save 儲存，由系統自動編譯並生成動態 Web 應用程式。

#### 🛡️ 無障礙優化核心
* **介面極簡化**：專為視障人士設計，移除複雜干擾元素，採用大面積、高對比的直覺式按鈕。
* **語音反饋機制**：拍照辨識後，系統將雲端分析結果在 **30 字內** 以口語化方式進行 TTS 語音朗讀（例如辨識出膳魔師保溫瓶，畫面顯示「完成！」並同步播報）。

### 🔌 項目五：紅外線測距與 TFT 螢幕即時顯示

#### 📋 實作說明
* **硬體通訊設定**：在程式中配置 `wire1.begin()`，成功啟用系統的 **I2C1 匯流排**（使用 `SDA1`, `SCL1` 接腳）。
* **驅動層優化**：深入修改 Realtek 硬體支援包底層中的 `VL53L0X.cpp` 驅動檔案，提升數據採集效率。
* **數據呈現**：將紅外線飛行時間（ToF）感測器讀取的數據，即時且精準地顯示於 TFT 螢幕上（單位：公分 cm）。

### 📐 項目六：MPU6050 陀螺儀姿態檢測

#### 💡 功能說明
* **姿態解算**：使用 **MPU6050** 六軸慣性傳感器獲取精確的朝向角（Heading Angle）。
* **硬體加速運算**：充分利用晶片內建的 **DMP（數位運動處理器）** 動態計算目前開發板與水平面之間的傾斜角度，並於 Arduino IDE 的序列埠監視器（Serial Monitor）即時輸出偏航角（Yaw）等數值。

![alt text](image-2.png)

### 💻 項目七：物聯網環境溫濕度即時監測

#### ⚙️ 功能實作
* **數據遠端整合**：修改 `ReceiveData` 範例程式，將 **DHT11** 溫濕度傳感器採集到的真實環境數據，動態嵌入至網頁端的 HTTP 回應原始碼中。
* **遠端監測監控**：行動裝置或電腦瀏覽器連線至指定靜態 IP（如 `10.190.176.137`），即可查看即時溫度（℃）與濕度（%），支援手動重新整理網頁獲取最新狀態。

### ♻️ 項目八：生成式 AI 視覺輔助回收物分類系統

## 📝 學習心得與技術收穫

### 📖 核心學習感想

1. **從「軟體堆疊」到「軟硬體底層整合」**
   在驅動 VL53L0X 與 MPU6050 的實作中，我學會了深入配置 I2C 匯流排並修改驅動層代碼（如 `VL53L0X.cpp`）。這讓我深刻體悟到，優秀的工程師不能僅停留在調用上層 API，必須掌握底層協議與暫存器架構，才能真正榨乾硬體效能並優化系統時序。

2. **生成式 AI：開發最強協同者，而非替代者**
   AI 確實能以極高的效率幫我搭建程式碼骨架（如 HTML 框架與基礎邏輯），但關鍵的引腳對接、訊號除錯與 Prompt 提示詞優化，仍高度取決於開發者自身的工程核心素養。**AI 是強大的槓桿，而技術底蘊則是控制它的支點。**

3. **「以人為本」的技術實踐思維**
   在盲人輔助系統的優化過程中，我學到了克制工程師「想把所有功能塞進網頁」的盲點。技術的價值不在於複雜度，而是在於能否解決痛點。改以極簡的高對比 UI，搭配字數限額的口語化 TTS 語音反饋，這才真正賦予了技術溫暖與智慧。

### 🎯 關鍵技術收穫

* 📟 **微處理器配置**：精通 **AMB82-mini** 的周邊周邊配置，包含 I2C 雙向通訊、SPI 螢幕驅動架構、以及 WiFi Web Server 架設與數據嵌入技術。
* 👁️ **Edge AI 部署**：實作 **YOLOv7** 輕量化神經網路的本地即時多目標偵測，並結合 WebSocket 技術實現低延遲影像串流，理解邊緣端即時運算優勢。
* ☁️ **多模態邊雲協同**：成功利用 Prompt 工程引導大語言模型進行視覺辨識，並於邊緣端串接 TTS 語音，完成「影像輸入 $\rightarrow$ 雲端推理 $\rightarrow$ 語音輸出」的技術閉環。
* 🔄 **CI/CD 開發流程**：熟悉利用 GitHub Pages 快速部署並動態測試前端應用的完整開發工作流。
