 學習心得與技術收穫
📖 核心學習感想
1.	從「軟體堆疊」到「軟硬體底層整合」： 在驅動 VL53L0X 與 MPU6050 時，我學會了深入配置 I2C 匯流排並修改驅動層代碼。這讓我理解到，優秀的工程師必須掌握底層協議與暫存器架構，才能真正發揮硬體效能。 
2.	生成式 AI：開發最強協同者： AI 能高效搭建代碼骨架（如 HTML 框架），但關鍵的引腳對接、訊號除錯與 Prompt 優化仍取決於開發者的工程核心素養。AI 是強大的槓桿，而技術底蘊則是控制它的支點。 
3.	「以人為本」的技術實踐： 在盲人輔助系統中，我深刻體悟到技術價值不在於複雜度，而是在於解決痛點。克制工程師思維，改以極簡 UI 與限額字數的 TTS 語音反饋，才是真正的智慧應用。 
🎯 關鍵技術收穫
•	微處理器配置：掌握 AMB82-mini 的 I2C 通訊、SPI 驅動與 WiFi Web Server 架設。 
•	Edge AI 部署：實作 YOLOv7 多目標偵測與 WebSocket 低延遲串流。 
•	多模態雲端協同：完成「影像輸入 $\rightarrow$ 雲端推理 $\rightarrow$ 語音輸出」的完整技術閉環。 
•	CI/CD 流程：熟悉利用 GitHub Pages 快速部署並測試前端應用的開發流程。 
📝 總結
這次實作成功引導我跨越了從傳統 IoT 到 AIoT 的門檻。我不僅累積了硬體除錯的扎實功力，更開拓了邊緣運算與大語言模型協同運作的眼界，這將成為我未來工程職涯中極具價值的實戰基礎。
